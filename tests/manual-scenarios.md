# MoonLight 운영 전 시나리오

1. 2026-10-29 17:00 예약이 성공한다.
2. 같은 17:00 슬롯에 두 사람이 동시에 예약하면 한 명만 성공한다.
3. 동일 대표자 전화번호로 17:15 추가 예약이 차단된다.
4. 17:00 예약을 17:15로 변경하면 17:00은 `available`, 17:15는 `reserved`가 된다.
5. 예약 취소 후 같은 전화번호로 다시 예약할 수 있다.
6. 2명 예약금은 2,000원, 4명은 4,000원으로 표시된다.
7. 1명과 5명은 예약할 수 없다.
8. 19:45는 예약할 수 있고 20:00 시작 슬롯은 없다.
9. 일반 사용자가 `paymentStatus`를 `confirmed`로 바꾸면 Firestore Rules가 거부한다.
10. 일반 사용자가 전체 MoonLight `bookings` 컬렉션을 조회하면 거부한다.
11. MoonLight 예약 현황 화면에는 예약자 개인정보가 내려오지 않는다.
12. 기존 귀로 예약 현황과 예약 조회는 MoonLight 예약 전후에 변하지 않는다.
